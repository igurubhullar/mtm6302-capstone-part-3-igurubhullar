This project is a quiz web application that dynamically fetches questions and categories from the QuizAPI, allowing users to select a category and difficulty level to participate in a personalized quiz experience. The application was built with a focus on interactivity, dynamic content rendering, and user progress tracking. Using JavaScript, the app retrieves data from the API, displays questions and answers dynamically, and provides real-time feedback on correctness. Scores are tracked using local storage, ensuring persistence across sessions, and users can reset scores or fetch new questions seamlessly. During development, challenges included parsing nested API responses, managing dynamic content, and ensuring session persistence. The project also prioritized clear and responsive UI feedback, such as highlighting selected answers and showing results. Future improvements could include features like timed quizzes, progress tracking across multiple sessions, and enhanced accessibility. This application demonstrates the integration of external APIs with interactive web development, creating an engaging and functional user experience.
